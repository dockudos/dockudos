## Mermaid

Use a `mermaid` fence:

````mdx
```mermaid
graph LR
  A[Write MDX] --> B[Build] --> C[Ship]
```
````

```mermaid
graph LR
  A[Write MDX] --> B[Build] --> C[Ship]
```

The Mermaid library is downloaded only on pages that have a diagram, and the diagram redraws when
the theme changes. Until it loads (and if it fails), the diagram source is shown.

## Math

Block equations go between `$$` lines. Inline equations also use `$$`:

```mdx
Inline $$E = mc^2$$ in a sentence.

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$
```

Inline $$E = mc^2$$ in a sentence.

$$
\int_0^1 x^2 \, dx = \tfrac{1}{3}
$$

A single `$` is not math, so prices like $5 and $10 are safe to write. KaTeX's stylesheet is added
only to pages that contain an equation.
