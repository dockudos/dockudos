## Generate the project

<Steps>
  <Step title="Run init">
    ```bash npx dockudos init my-docs ``` It asks for a name and creates a
    folder with everything the site needs.
  </Step>
  <Step title="Start the dev server">
    ```bash cd my-docs npm install npm run dev ```
  </Step>
</Steps>

<Checkpoint>
  Open `http://localhost:3000`. You should see the home page of your new site,
  with a sidebar and a search box.
</Checkpoint>

## What you have

<Files>
  <Folder name="my-docs" defaultOpen>
    <Folder name="docs" defaultOpen>
      <File name="index.mdx" />
      <File name="quickstart.mdx" />
    </Folder>
    <File name="docs.json" />
    <File name="package.json" />
  </Folder>
</Files>

Your pages are the `.mdx` files in `docs/`. `docs.json` holds the site's name, theme and sidebar. You will use both in the
next step.

<Hint title="The port is already in use?">
  Start the server on another port: `npm run dev -- --port 3001`.
</Hint>
