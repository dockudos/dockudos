dockudos turns a folder of MDX files and a `docs.json` into a documentation site with navigation,
table of contents, dark mode, syntax highlighting and a set of ready-made components. It runs inside
a Next.js App Router project, so you keep the whole Next.js toolbox.

## What you get

- **Content from files.** Pages are MDX in `docs/`. The URL comes from the file path; the title and
  description from frontmatter.
- **Navigation you control.** List pages in `docs.json`, or leave it empty and the sidebar follows
  your folders.
- **A real theme.** One brand color generates a palette for light and dark mode that meets WCAG AA
  contrast. Six layouts, switchable per site or per page.
- **Components for docs.** Callouts, tabs, steps, cards, file trees, type tables, diagrams, math and more.
- **Feedback from readers.** A thumbs up or down and an optional comment under every page, read with `dockudos kudos`. See [Kudos](/components/kudos).
- **Checks that fail the build.** An invalid `docs.json` or a broken link stops `dockudos build` and
  tells you the file and line.
- **A headless core.** Config validation, the page tree, breadcrumbs and the table of contents work
  without React. See [the headless core](/reference/headless-core).
