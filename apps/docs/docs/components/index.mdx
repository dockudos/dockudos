Every component below is available in every MDX file. They work in light and dark mode, and the
interactive ones work from the keyboard.

## Aliases

Some components are available under a second name, so content written for other tools works unchanged.

| Name                                                | Same as                                              |
| --------------------------------------------------- | ---------------------------------------------------- |
| `Note`, `Info`, `Tip`, `Check`, `Warning`, `Danger` | [`Callout`](./callout.mdx) with that `type`          |
| `AccordionGroup`                                    | [`Accordion`](./accordion.mdx)'s group, `Accordions` |
| `CardGroup`                                         | [`Cards`](./cards.mdx)                               |
| `Files`, `Folder`, `File`                           | [`Tree`](./tree.mdx), `Tree.Folder` and `Tree.File`  |
| `pre`                                               | [`CodeBlock`](./code-block.mdx)                      |
| `img`                                               | [`Images`](./image.mdx)                              |
| `table`                                             | Every Markdown table: a scrolling, rounded frame     |

## Motion

Menus, accordions, tabs, tooltips, dialogs and file trees animate as they open and close, and page
titles and steps ease in. Everything that moves is switched off for visitors who ask their system to
reduce motion.

## Replace a component

Components are looked up by name in your `mdx-components.tsx`. Pass your own under the same name
and every use in every page changes:

```tsx title="mdx-components.tsx"
import { defineMdxComponents } from '@dockudos/next/mdx-components';
import type { MDXComponents } from 'mdx/types';
import { MyCallout } from './components/my-callout';

export function useMDXComponents(components: MDXComponents): MDXComponents {
  return {
    ...defineMdxComponents({
      Callout: MyCallout, // replaces the built-in
      Pricing: PricingTable, // a new component, available everywhere
    }),
    ...components,
  };
}
```

Standard elements can be replaced the same way: `a`, `img`, `pre`, `table`. The built-in `img` is the
zoomable image and `pre` is the code block, so replacing them gives up zoom and the copy button.

Your component receives the same props as the built-in one. The [headless
core](../reference/headless-core.mdx) and `@dockudos/ui` export the originals, so you can wrap
them instead of rewriting them.
