The tab labels come from the `value` of each `<Tab>`, in order. Arrow keys move between tabs, Home and
End jump to the first and last, and the panel is reachable with Tab.

## Keeping tabs in step

Give related tab sets the same `groupId`. Choosing a tab in one switches all of them, and the choice
is remembered on the next visit. The `package-install` code block uses `groupId="package-manager"`.
