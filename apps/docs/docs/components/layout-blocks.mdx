## Columns

`Columns` lays content out side by side. Anything can be a column: cards, code blocks, plain Markdown.

<Columns cols={2}>
  <Card title="Before">The old way.</Card>
  <Card title="After">The new way.</Card>
</Columns>

```mdx
<Columns cols={3}>
  <Card title="One">…</Card>
  <Card title="Two">…</Card>
  <Card title="Three">…</Card>
</Columns>
```

`cols` is 2, 3 or 4, and defaults to 2. Columns stack into one on phones; four columns drop to two on a tablet.
Each direct child is one column.

`Columns` has no borders of its own. To make a grid of linked boxes, use [Cards](./steps-and-cards.mdx).

## Frame

`Frame` puts a border and an optional caption around an image, a video or a diagram.

<Frame caption="A blue box, framed with a caption">
  <img src="/example.png" alt="A blue rectangle" width={120} height={60} />
</Frame>

```mdx
<Frame caption="The dashboard">![The dashboard](./dashboard.png)</Frame>
```

The content is centered and never wider than the frame. The caption is a real `figcaption`, so it is read with the image.
Use a caption to say what the reader should notice; `alt` text still describes the image itself. Images inside a frame
can still be zoomed, see [Images](../guides/images.mdx).

## Expandable

`Expandable` is one collapsible block, for optional detail such as nested properties of an API field.

<Expandable title="Show the details">
  Optional content that most readers can skip. It is a native `details` element:
  it works without JavaScript, and Enter or Space opens it.
</Expandable>

```mdx
<Expandable title="Show the details" defaultOpen>
  …
</Expandable>
```

Use [Accordion](./accordion.mdx) for a group of related questions and `Expandable` for a single optional block. It
animates as it opens, unless the visitor prefers reduced motion, and is opened on paper.
