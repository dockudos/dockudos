`Tree` draws a project's structure, with `Tree.Folder` and `Tree.File` as its parts. It is for showing the shape of a project; a code block is better for file contents.

<Tree>
  <Tree.Folder name="docs" defaultOpen>
    <Tree.File name="index.mdx" />
    <Tree.Folder name="guides">
      <Tree.File name="writing.mdx" />
    </Tree.Folder>
  </Tree.Folder>
  <Tree.File name="docs.json" />
  <Tree.File name="next.config.mjs" />
</Tree>

```mdx
<Tree>
  <Tree.Folder name="docs" defaultOpen>
    <Tree.File name="index.mdx" />
    <Tree.Folder name="guides">
      <Tree.File name="writing.mdx" />
    </Tree.Folder>
  </Tree.Folder>
  <Tree.File name="docs.json" />
</Tree>
```

Folders open and close with <Kbd>Enter</Kbd> or <Kbd>Space</Kbd>, and animate unless the visitor prefers reduced
motion. A folder starts closed unless it has `defaultOpen`; folders can nest as deep as you need.

## Custom icons

`Tree.File` and `Tree.Folder` take an `icon`: any element, such as an SVG, an `<img>` or an icon component.
`Tree.Folder` also takes `openIcon`, shown while it is open; without it `icon` is used for both states.

<Tree>
  <Tree.Folder
    name="src"
    defaultOpen
    icon={<span>📁</span>}
    openIcon={<span>📂</span>}
  >
    <Tree.File name="app.ts" icon={<span>🟦</span>} />
    <Tree.File name="notes.md" />
  </Tree.Folder>
</Tree>

```mdx
<Tree>
  <Tree.Folder
    name="src"
    defaultOpen
    icon={<MyFolder />}
    openIcon={<MyFolderOpen />}
  >
    <Tree.File name="app.ts" icon={<img src="/ts.svg" alt="" />} />
  </Tree.Folder>
</Tree>
```

Icons are decorative: they are hidden from screen readers, and sized to 1rem. Unlike most `icon` props, these take an
element and not a name; for a named [icon](./icons.mdx), write `icon={<Icon name="rocket" />}`.

## Aliases

`Files`, `Folder` and `File` are the same components as `Tree`, `Tree.Folder` and `Tree.File`, so content written for other tools
works as it is:

```mdx
<Files>
  <Folder name="src" defaultOpen>
    <File name="index.ts" />
  </Folder>
</Files>
```

## Accessibility and printing

The tree is a labelled `tree` with `treeitem` rows, and a folder reports whether it is expanded. On paper every folder is
opened so the whole tree is shown.
