```mdx
<Timeline>
  <TimelineItem title="Core library" date="2026 Q1" status="done">
    Pages, navigation and search.
  </TimelineItem>
  <TimelineItem title="API reference" date="2026 Q2" status="current" />
</Timeline>
```

A timeline is an ordered list, in the order you write it. The status is a label written in words ("Done", "In progress",
"Planned"), never only a color. For release notes use [Update](./update.mdx), which is meant for entries that
read as a changelog.
