## Tooltip

A tooltip explains a term without leaving the sentence. Hover or focus the word

<Tooltip tip="MDX is Markdown that can use components.">MDX</Tooltip> to see the
hint.

```mdx
Hover <Tooltip tip="MDX is Markdown that can use components.">MDX</Tooltip>.
```

The term is underlined with dots so readers know it does something. It is focusable, so keyboard users get the hint on
focus, and <Kbd>Esc</Kbd> closes it. The hint opens after a short delay and keeps clear of the edge of the screen.

<Callout type="warning">
  Put essential information in the text, not only in a tooltip. Touch screens
  have no hover, and a tooltip is not included when someone prints the page.
</Callout>

## Banner

A banner is an announcement strip across the full width: a release, an event, a migration notice.

<Banner id="docs-example-banner">
  dockudos 0.x is available. This banner can be dismissed.
</Banner>

```mdx
<Banner id="v1-launch">Version 1 is out.</Banner>
```

### Dismissing

With an `id` the banner has a dismiss button and stays dismissed for that visitor: the choice is stored in the browser
under that id. Without an `id` it cannot be dismissed. Change the `id` when the message changes, such as
`v2-launch`, and everyone sees the new banner even if they closed the old one.

Dismissal is per browser. If storage is blocked the banner is still shown, and closing it lasts until the page reloads.

### Gradient

`variant="rainbow"` replaces the solid color with a soft gradient:

<Banner variant="rainbow">A gentler look for a quiet announcement.</Banner>

```mdx
<Banner variant="rainbow">A gentler look for a quiet announcement.</Banner>
```

### On every page

A banner placed in a page shows only in that page. To show one on every page, render the component from
`@dockudos/ui` in your root layout, next to `DocsRoot`:

```tsx title="src/app/layout.tsx"
import { Banner } from '@dockudos/ui';

// …
<body>
  <Banner id="v1-launch">Version 1 is out.</Banner>
  <DocsRoot icons={site.icons}>{children}</DocsRoot>
</body>;
```

off printed pages.
