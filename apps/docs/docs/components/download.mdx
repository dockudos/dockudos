```mdx
Get <Download href="/files/guide.pdf" size="2.4 MB">the guide</Download>.
```

The label can be anything. The file's type is read from its name and shown with the size you give, as in "(PDF, 2.4 MB)",
so readers know what they are getting before they click. Put files in `public/`, and link to them with a path that starts with `/`.

`download` only works for files on your own site. Files on another site open as a normal link.
