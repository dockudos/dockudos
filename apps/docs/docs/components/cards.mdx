`Cards` is a grid; each `Card` has a title, optional text and an optional link.

<Cards>
  <Card title="Navigation" href="/guides/navigation" icon="compass">
    A card with an internal link and an icon.
  </Card>
  <Card title="Next.js" href="https://nextjs.org">
    A card with an external link.
  </Card>
  <Card title="No link">A card that is only information.</Card>
</Cards>

```mdx
<Cards columns={2}>
  <Card title="Navigation" href="/guides/navigation" icon="compass">
    Internal link.
  </Card>
  <Card title="Next.js" href="https://nextjs.org">
    External link.
  </Card>
</Cards>
```

With an `href` the whole card is a link, with a lift on hover and a visible focus ring. Internal links use the
router, so navigation is instant; external links open in a new tab. A card without an `href` is a plain box.

## Columns

`columns` (or `cols`, the same prop under the name other tools use) is `1`, `2` or `3`. Wide screens use that many,
tablets use two at most, and phones always use one.

<Cards cols={3}>
  <Card title="One">First.</Card>
  <Card title="Two">Second.</Card>
  <Card title="Three">Third.</Card>
</Cards>

```mdx
<Cards cols={3}>
  <Card title="One">…</Card>
  <Card title="Two">…</Card>
  <Card title="Three">…</Card>
</Cards>
```

`CardGroup` is `Cards` under another name, for content written for other tools. For cards with a screenshot on top
see [Tile](./tile.mdx). For a layout that is not a grid of cards see [Columns](./columns.mdx).

## Images, horizontal cards and arrows

`img` puts a picture across the top of a card. `horizontal` puts the icon beside the text instead of above it. `arrow`
shows a small arrow on a linked card; it is on by default for links to other sites.

<Cards>
  <Card
    title="Horizontal"
    icon="rocket"
    horizontal
    href="/getting-started/quickstart"
    arrow
  >
    Icon on the side, with an arrow.
  </Card>
  <Card title="With a picture" img={example.src}>
    The picture spans the top.
  </Card>
</Cards>

```mdx
<Card title="Horizontal" icon="rocket" horizontal href="/quickstart" arrow>
  Icon on the side, with an arrow.
</Card>
<Card title="With a picture" img={example.src}>
  The picture spans the top.
</Card>
```

The picture is decorative (empty `alt`); say what matters in the title and text. For a card whose point is its
preview, use [Tile](./tile.mdx).
