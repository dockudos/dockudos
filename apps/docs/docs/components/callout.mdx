A callout is a `role="note"` region; its icon is decorative and hidden from screen readers.

## Shorthands

`Note`, `Info`, `Tip`, `Check`, `Warning` and `Danger` are the same callouts under shorter names, so content written for
other documentation tools works unchanged:

```mdx
<Warning>This deletes the project.</Warning>
<Check title="Done">Everything is set up.</Check>
```
