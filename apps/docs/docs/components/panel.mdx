On a wide screen a `Panel` sits in the right-hand column, in place of "On this page", and stays in view as you scroll. On a
phone, and on paper, it is just part of the page. This page uses one.

const res = await fetch('https://api.acme.dev/v1/users', {

- A `Panel` can hold anything, not just examples: a summary, a related-links box, a video.
- Put one `Panel` per page. A page with a panel has no table of contents column.
- With [RequestExample](./request-example.mdx), [ResponseExample](./response-example.mdx), [Endpoint](./endpoint.mdx) and
  [ParamField](./param-field.mdx) this is enough to write an API reference by hand.

## Accessibility and printing

A `Panel` is an `aside` labelled "Examples". On a phone, and on paper, it is not pinned: it stays in the text where you wrote
it.
