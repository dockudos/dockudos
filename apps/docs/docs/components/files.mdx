---
title: Files
description: Show a file tree.
---

<Files>
  <Folder name="docs" defaultOpen>
    <File name="index.mdx" />
    <Folder name="guides">
      <File name="writing.mdx" />
    </Folder>
  </Folder>
  <File name="docs.json" />
  <File name="next.config.mjs" />
</Files>

```mdx
<Files>
  <Folder name="docs" defaultOpen>
    <File name="index.mdx" />
    <Folder name="guides">
      <File name="writing.mdx" />
    </Folder>
  </Folder>
  <File name="docs.json" />
</Files>
```

Folders open and close with Enter or Space. `defaultOpen` starts one open.
