`Files` draws a project's structure. It is for showing the shape of a project; a code block is better for file contents.

<Files>
  <Folder name="docs" defaultOpen>
    <File name="index.mdx" />
    <Folder name="guides">
      <File name="writing.mdx" />
    </Folder>
  </Folder>
  <File name="docs.json" />
  <File name="next.config.mjs" />
</Files>

```mdx
<Files>
  <Folder name="docs" defaultOpen>
    <File name="index.mdx" />
    <Folder name="guides">
      <File name="writing.mdx" />
    </Folder>
  </Folder>
  <File name="docs.json" />
</Files>
```

Folders open and close with <Kbd>Enter</Kbd> or <Kbd>Space</Kbd>, and animate unless the visitor prefers reduced
motion. A folder starts closed unless it has `defaultOpen`; folders can nest as deep as you need.

## Custom icons

`File` and `Folder` take an `icon`: any element, such as an SVG, an `<img>` or an icon component.
`Folder` also takes `openIcon`, shown while it is open; without it `icon` is used for both states.

<Files>
  <Folder
    name="src"
    defaultOpen
    icon={<span>📁</span>}
    openIcon={<span>📂</span>}
  >
    <File name="app.ts" icon={<span>🟦</span>} />
    <File name="notes.md" />
  </Folder>
</Files>

```mdx
<Files>
  <Folder
    name="src"
    defaultOpen
    icon={<MyFolder />}
    openIcon={<MyFolderOpen />}
  >
    <File name="app.ts" icon={<img src="/ts.svg" alt="" />} />
  </Folder>
</Files>
```

Icons are decorative: they are hidden from screen readers, and sized to 1rem. Unlike most `icon` props, these take an
element and not a name; for a named [icon](./icons.mdx), write `icon={<Icon name="rocket" />}`.

## Tree

`Tree` is `Files` under the name other tools use, with `Tree.Folder` and `Tree.File` for `Folder` and `File`, so content written
for them works as it is:

<Tree>
  <Tree.Folder name="src" defaultOpen>
    <Tree.File name="index.ts" />
  </Tree.Folder>
</Tree>

```mdx
<Tree>
  <Tree.Folder name="src" defaultOpen>
    <Tree.File name="index.ts" />
  </Tree.Folder>
</Tree>
```

## Accessibility and printing

The tree is a labelled `tree` with `treeitem` rows, and a folder reports whether it is expanded. On paper every folder is
opened so the whole tree is shown.
