## CopyText

Inline code with a copy button, for a command, a URL or an ID the reader will paste.

Install it with <CopyText>npm install dockudos</CopyText> and open <CopyText value="http://localhost:3000">localhost:3000</CopyText>.

```mdx
Install it with <CopyText>npm install dockudos</CopyText>.

<CopyText value="the real value">shown text</CopyText>
```

The button copies the shown text, or `value` if you give one, so you can show a shortened version and copy the whole.
It turns into a tick, and announces "Copied to clipboard" or "Copy failed" to screen readers. It is left off printed
pages, where the text stays. For several lines, use a [code block](./code-block.mdx), which has its own copy button.

## Hero

A landing-page banner with an optional small label (the eyebrow), a headline, a sentence and buttons.

<Hero eyebrow="New" title="Docs that ship" description="Write MDX. Get a site.">
  <LinkButton href="/getting-started/quickstart">Get started</LinkButton>
  <LinkButton href="/components" variant="secondary">
    Components
  </LinkButton>
</Hero>

```mdx
<Hero eyebrow="New" title="Docs that ship" description="Write MDX. Get a site.">
  <LinkButton href="/quickstart">Get started</LinkButton>
  <LinkButton href="https://github.com/acme/acme" variant="secondary">
    GitHub
  </LinkButton>
</Hero>
```

Use a `Hero` at the top of a page with `layout: home`; see [Layouts](../guides/layouts.mdx). The page's own title is
still the single `h1`; the hero headline is an `h2`, so the outline stays correct.

## LinkButton

A link that looks like a button. It is a real link, so it can be opened in a new tab and read as a link by assistive
technology. Use it inside a `Hero`, or anywhere else a call to action belongs.

Internal paths use the router. Links to other sites open in a new tab, and are announced as such.

<LinkButton href="/getting-started/quickstart">Primary</LinkButton>
<LinkButton href="/getting-started/quickstart" variant="secondary">
  Secondary
</LinkButton>
