`View` shows one version of some content at a time. Give each version a `title`; when a page has more than one title, a
selector appears above the first view and the reader picks which one to see.

## How it behaves

- The first view is shown, unless the reader chose another on this site before: the choice is remembered in the browser.
- Views with the same `title` belong together. Put one `View` per title for each part of the page that differs, and use the
  same titles everywhere: choosing "Python" switches every part at once.
- Without scripting, and on paper, every view is shown, each labelled with its title, so nothing is hidden from
  a printed page or from "Copy page".
- The selector is a labelled native `select`, so it works with the keyboard and with screen readers.

## View, Tabs or CodeGroup?

| Use                           | When                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------- |
| [Tabs](./tabs.mdx)            | A short set of alternatives next to each other, such as one step done on two systems. |
| [CodeGroup](./code-block.mdx) | The same code in several languages.                                                   |
| `View`                        | Whole sections of a page, with headings, that differ by language or setup.            |

The headings inside a view are all in the page's table of contents. Keep them the same in each view where you can.
