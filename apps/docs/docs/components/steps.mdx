`Steps` is a numbered procedure. Each `Step` has a title and a body, and the numbers are drawn for you.

<Steps>
  <Step title="Install">Add the packages.</Step>
  <Step title="Configure">Create `docs.json`.</Step>
  <Step title="Ship">Run the build.</Step>
</Steps>

```mdx
<Steps>
  <Step title="Install">Add the packages.</Step>
  <Step title="Configure">Create `docs.json`.</Step>
</Steps>
```

Any content can go inside a step, including code blocks, images and callouts. Put a blank line between
a step's opening tag and a code block so the block is parsed as code.

## Icons in place of numbers

An `icon` replaces the number of one step, for a procedure whose steps are not a count:

<Steps>
  <Step title="Download" icon="download">
    Get the installer.
  </Step>
  <Step title="Done" icon="flag">
    Nothing more to do.
  </Step>
</Steps>

```mdx
<Step title="Download" icon="download">
  Get the installer.
</Step>
```

piece where it can be.
