`Kbd` shows a key as a keycap.

Press <Kbd>Ctrl+K</Kbd> to search, or <Kbd>Esc</Kbd> to close.

```mdx
Press <Kbd>Ctrl+K</Kbd>, or <Kbd>Esc</Kbd>.
```

A `+` inside the text separates keys, so `Ctrl+K` shows two keys. To show a literal plus key, pass
it as an expression: <Kbd>{'+'}</Kbd> is `<Kbd>{'+'}</Kbd>`. Write the key names as you want readers to see
them; `Kbd` does not translate them.

[Shortcut](./shortcut.mdx).
