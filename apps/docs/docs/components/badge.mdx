A badge is a small inline label for a status: new, beta, deprecated, a version.

<Badge>Default</Badge> <Badge color="blue">Info</Badge>
<Badge color="green">New</Badge> <Badge color="amber">Beta</Badge>
<Badge color="red">Deprecated</Badge>

```mdx
This API is <Badge color="amber">Beta</Badge>.
```

It sits in a line of text, a heading, a table cell or a card. The colors share the palette of
[callouts](./callout.mdx): `gray` (the default), `blue`, `green`, `amber` and `red`. An unknown color renders as gray.
Color is never the only signal: put the meaning in the text, as in "Deprecated".
