## Tile

A `Tile` is a card with a preview on top. Use it for templates, examples, themes and showcases. Put several in `Cards`
to make a gallery.

<Cards cols={3}>
  <Tile
    title="Starter"
    description="A small site"
    href="/getting-started/quickstart"
  >
    <img
      src="/example.png"
      alt="A blue rectangle standing in for a screenshot"
      width={120}
      height={60}
    />
  </Tile>
  <Tile title="Docs" description="With tabs" href="/guides/navigation">
    <img src="/example.png" alt="" width={120} height={60} />
  </Tile>
  <Tile title="Plain" description="No link" />
</Cards>

```mdx
<Cards cols={3}>
  <Tile title="Starter" description="A small site" href="/starter">
    <img src="/starter.png" alt="Screenshot of the starter" />
  </Tile>
</Cards>
```

The preview has a fixed 16:10 shape and crops the image to fill it, so tiles line up whatever size the images are.
Anything can be the preview: an image, an SVG, a diagram or a [Mermaid](./mermaid.mdx) chart. With an `href` the whole
tile is a link; internal links use the router and external links open in a new tab, which is announced to screen readers.

Give the preview image `alt` text that describes it, or an empty `alt` if the title already says it all.

## Colors

`Colors` is a palette for brand and design-token pages. Click a swatch to copy its value.

<Colors
  title="Brand"
  items={[
    { name: 'Primary', value: '#4f46e5' },
    { name: 'Ink', value: '#18181b' },
    { name: 'Success', value: '#16a34a' },
    { name: 'Warning', value: '#d97706' },
  ]}
/>

```mdx
<Colors title="Brand" items={[{ name: 'Primary', value: '#4f46e5' }]} />
```

Any CSS color works: hex, `rgb()`, `oklch()`, or a variable such as `var(--primary)`. Without a `title` the palette has no
caption. After a copy the swatch shows a tick and screen readers hear "Copied Primary".

<TypeTable
  type={{

      description:

Each swatch is a button named "Copy Primary, #4f46e5", so the color is available to anyone, not only those who can
see it. Swatches print with their value written out.
