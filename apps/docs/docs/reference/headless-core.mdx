---
title: The headless core
description: Use dockudos without React.
---

`@dockudos/core` has no React and no Next.js. It does the work that is not about pixels, so you can
build a different frontend, a script or a CI check on the same logic. It runs in Node and in the
browser, except `@dockudos/core/node`, which reads files and spawns `git`.

```ts
import {
  buildNavigation,
  buildPageTree,
  breadcrumb,
  extractToc,
  parseConfig,
  prevNext,
} from '@dockudos/core';

const config = parseConfig({
  name: 'Acme',
  navigation: [
    { tab: 'Docs', groups: [{ group: 'Start', pages: ['index', 'guide'] }] },
  ],
});
const tree = buildPageTree(['index.mdx', 'guide.mdx']);
const nav = buildNavigation(config, tree);

breadcrumb(nav, '/guide'); // [{ title: 'Docs' }, { title: 'Start' }, { title: 'Guide', href: '/guide' }]
prevNext(nav, '/guide'); // { prev: <page for /> }
extractToc('## One\n### Two'); // [{ id: 'one', text: 'One', depth: 2 }, ...]
```

A script that fails when a page is missing from the navigation, using nothing but the core:

```ts title="check-nav.ts"
import { buildNavigation } from '@dockudos/core';
import { discoverPages, loadConfig } from '@dockudos/core/node';

const config = await loadConfig(process.cwd());
const tree = await discoverPages('docs', { prefix: config.urlPrefix });
const { unlisted } = buildNavigation(config, tree);

if (unlisted.length) {
  console.error(
    'Not in the navigation:',
    unlisted.map((p) => p.file).join(', '),
  );
  process.exit(1);
}
```
