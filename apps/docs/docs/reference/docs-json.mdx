---
title: docs.json
description: Every key of the site configuration.
---

`docs.json` sits at the project root. Unknown keys are rejected, so a typo fails the build instead
of being ignored. For editor completion and validation, point `$schema` at the bundled JSON Schema:

```json
{ "$schema": "./node_modules/@dockudos/core/docs.schema.json", "name": "Acme" }
```

Errors name the key and the file:

```text
Invalid docs config in /my-docs/docs.json:
  - name: Invalid input: expected string, received undefined
  - unknown key theem
  - theme.layout: Invalid option: expected one of "docs"|"notebook"|"spacious"|"flux"|"glass"|"home"
```

## navigation

A list of tabs. Each tab is one of:

<TypeTable
  type={{
    tab: {
      type: 'string',
      required: true,
      description: 'Label in the navbar.',
    },
    groups: {
      type: 'Group[]',
      required: true,
      description: 'Sidebar content of the tab.',
    },
    href: {
      type: 'string',
      required: true,
      description: 'Instead of groups: makes the tab a link.',
    },
  }}
/>

A group is `{ group: string, pages: Item[] }`, and an item is a page id (string), a link
`{ title: string, href: string }` or another group. See [navigation](../guides/navigation.mdx).
