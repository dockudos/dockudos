```text
dockudos <command> [options]
```

## init

```bash
dockudos init [folder] [--name <text>] [--package-manager <npm|pnpm|yarn|bun>] [--yes]
```

Creates a site from the default template. Asks for anything you did not pass, unless `--yes` or the
terminal is not interactive. Fails if the folder has files in it. See [installation](../getting-started/installation.mdx).

## dev

```bash
dockudos dev [next dev options]
```

Runs `next dev` from your project. Arguments after `dev` go to Next.js, for example `-p 4000`.
MDX and component changes hot-reload through Next.js. A change to `docs.json` restarts the server
(it is read when Next.js starts); if the new file is invalid, the problem is printed and the running
server stays up.

## build

```bash
dockudos build [next build options]
```

0. Runs [`sync`](#sync) when `docs.json` has `sources` (skip with `--no-sync`).
1. Runs [`generate`](#generate) when `docs.json` has API or reference sources.
2. Validates `docs.json`, the frontmatter of every page, navigation entries and redirects.
3. Checks every link, anchor and image. Any error stops here.
4. Runs [`index`](#index): the search index, reusing pages that did not change, plus embeddings when configured.
5. Runs `next build`.

Exits with the status of `next build`, or 1 when a check fails, with the reason printed.

`--static` writes a plain-file site to `out/` (see [Static export](../guides/static-export.mdx)); `--base-path /name` is for hosts that serve from a sub-path.

## generate

```bash
dockudos generate [--force]
```

Writes the pages and data for every source in `openapi.sources` and `reference.sources` of `docs.json`: one page for each
operation of an OpenAPI spec, the channels of an AsyncAPI spec, the fields of a GraphQL schema, the exports of TypeScript
files and the modules of a Python package. A spec that did not change since the last run is skipped (`--force` ignores
that, for example after a file the spec refers to changed). Pages that left the spec are removed; files that were not
written by this command are never touched. A spec that cannot be fetched or parsed stops the command with its location
and the reason. `dev`, `build`, `index` and `broken-links` run it first; `dev` runs it again when a local spec changes.
See [API reference](../guides/api-reference.mdx).

## index

```bash
dockudos index
```

Builds the [search index](../guides/search.mdx#the-content-index) into `.dockudos/index.json` without building the site, and
computes [embeddings](../guides/ask-the-docs.mdx#meaning-based-search) when `ai.embeddings` is configured. `dockudos build` does the same
as a step. Keys are read from the environment, then from `.env.local` and `.env`.

## mcp

```bash
dockudos mcp
```

Serves this project's docs to AI coding tools over the [Model Context Protocol](../guides/mcp.mdx), on standard input and output.
Nothing else is written to standard output.

## broken-links

```bash
dockudos broken-links [--external]
```

See [broken links](../guides/broken-links.mdx). Exit status 0 when there are no errors, 1 otherwise.

## pdf

```bash
dockudos pdf [-o <file>] [--no-build] [--page-size A4|Letter] [--chrome <path>] [--port <n>] [--timeout <s>]
            [--user <user:password>] [--token <token>] [--version <name>] [--locale <code>] [--path </section>]
```

Builds the site (unless `--no-build`), serves it on a free local port, and prints the `/print` page,
which holds every page, into one PDF. `--version` and `--locale` print one version and language, and `--path /guides` only that
section (an address inside the version and language). Needs a Chrome or Chromium. If `/print` is [protected](../guides/protecting-pages.mdx#the-pdf-of-a-protected-site), give `--user` or `--token`. See
[Printing and PDF](../guides/printing.mdx#the-whole-site-as-one-pdf).

## epub

```bash
dockudos epub [-o <file>] [--version <name>] [--locale <code>] [--path </section>]
```

Writes the docs as an EPUB 3 book, in the order of the sidebar, with the sidebar groups as the table of contents. It needs
no server and no browser. Pages behind an `access` rule and pages that are only shown in another language are left out, and the
command says how many. Images that are files of the project are embedded; others show their alt text. See
[Printing and PDF](../guides/printing.mdx#epub).

## sync

```bash
dockudos sync [name...]
```

Fetches or converts the [content sources](../guides/sources.mdx) of `docs.json` and writes their pages into the docs folder. Name
sources to run only those. Pages the source no longer has are removed, files you wrote by hand in the same folder never are, and a
file is only rewritten when its content changed. `dockudos build` runs it first; `--no-sync` skips that.

## kudos

```bash
dockudos kudos [--path <page>] [--json] [--file <log>]
```

Prints the votes and comments collected by the [kudos widget](../components/kudos.mdx), per page,
busiest first. Reads `.dockudos/kudos.jsonl` unless `--file` says otherwise, and reports lines it could
not read instead of dropping them silently.

## Exit status

| Status | Meaning                                                        |
| ------ | -------------------------------------------------------------- |
| 0      | Success                                                        |
| 1      | A check failed, a flag was wrong, or the command could not run |
| other  | `dev` and `build` return what `next` returned                  |

`dockudos --help` and `dockudos --version` work as expected.
