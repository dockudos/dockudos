      type: 'boolean',
      description:
        'Set to false to hide the kudos (feedback) widget on this page.',
    },

      type: 'string',
      description:
        'An icon name, shown beside the page in the sidebar and in search. See Icons.',
    },
  }}
/>

Any other key is kept as written, so you can add your own metadata. A value of the wrong type, or an
empty `title`, stops the build with the file name and key.

Frontmatter is YAML between two `---` lines at the very top of the file.
